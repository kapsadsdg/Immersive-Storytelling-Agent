Optional sound files for the web interface
==========================================

Put your own audio files in this folder. Every file is optional. With no files,
the interface is simply silent. Accepted formats: .mp3, .ogg, .m4a, .wav

  thinking-calm     music while the agents work, story tension 1-3
  thinking-tense    music while the agents work, story tension 4-7
  thinking-climax   music while the agents work, story tension 8-10
  thinking          fallback music for any tension band without its own file
  click             short sound played when a button is clicked

Examples: thinking.mp3, thinking-climax.ogg, click.wav

The music loops while a turn is being written, so tracks that loop cleanly work
best. Only use audio you have the rights to use and share.

After adding or removing files, reload the page. No server restart is needed.
